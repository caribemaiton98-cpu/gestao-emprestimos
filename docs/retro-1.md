# Retrospetiva — Iteração 1

## 1. Participação

O projeto foi desenvolvido individualmente, sem participação de colegas na implementação. No entanto, contei com o apoio do ChatGPT como ferramenta de inteligência artificial para esclarecer dúvidas, apoiar a implementação de funcionalidades e ajudar na resolução de dificuldades técnicas, especialmente na utilização do Git e do GitHub.

A implementação, execução dos comandos, testes e acompanhamento do projeto foram realizados por mim.

## 2. O que correu bem

Foi possível desenvolver a base do sistema de gestão de empréstimos de equipamento multimédia, incluindo o catálogo de equipamentos e a funcionalidade de reservas.

Os testes automatizados permitiram verificar o comportamento das funcionalidades implementadas. Também foi possível configurar o GitHub Actions para executar os testes automaticamente após o envio de alterações para o repositório.

## 3. Principais dificuldades

A principal dificuldade foi realizar as ligações e operações com o GitHub, nomeadamente sincronizar o projeto local com o repositório remoto e compreender os comandos necessários para enviar as alterações.

## 4. O que poderia ser melhorado

Numa próxima iteração, pretendo melhorar a organização e atualização do `BACKLOG.md`, tornando mais claro o estado das tarefas e o trabalho a realizar.

Também pretendo melhorar a utilização do Git e do GitHub, para gerir os commits, as etiquetas e o envio de alterações de forma mais organizada e autónoma.

## 5. Ações para a próxima iteração

* Atualizar o `BACKLOG.md` de forma regular.
* Organizar melhor as tarefas antes de iniciar a implementação.
* Praticar os comandos Git e o fluxo de trabalho com o GitHub.
* Continuar a executar os testes automatizados durante o desenvolvimento.
